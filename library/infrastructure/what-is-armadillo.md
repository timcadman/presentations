- **Open-source server** that holds your data and runs DataSHIELD on it, built by the UMCG as part of MOLGENIS
- **Lightweight** — no database engine, so large tables run on modest hardware, and no sysadmin to maintain it
- **Profiles** — DataSHIELD packages ship as versioned Docker images, added or updated from the interface
- **A web interface** for data managers: projects, uploads, users, packages
- **Institutional login** through OIDC — no passwords in R

</v-clicks>
